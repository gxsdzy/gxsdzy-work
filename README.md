**English** | [简体中文](README.zh-CN.md)

**Guangxi Vocational College of Water Resources and Electric Power**
(广西水利电力职业技术学院, short name 广西水电职院, abbreviation `gxsdzy`, website [gxsdxy.cn](https://www.gxsdxy.cn)).

Created: September 2026 (2026–2027 academic year, semester 1).

## Folders

### `班会/` — Class meetings

Slides and materials for class meetings (班会) of
**Computer Application Technology, Class 6** (计算机应用技术6班), 2026 cohort.

- `计算机应用技术6班新生主题班会.pptx` — orientation class meeting for new students.

### `前端设计与开发/` — Front-end Design and Development

Course slides and teaching materials for the course
**《前端设计与开发》** (Front-end Design and Development).

- `《前端设计与开发》项目1.pptx` — Project 1 slides.

Files are organized by project (项目1, 项目2, …), following the course syllabus.

## Conventions

- Top-level folder name is ASCII (`gxsdzy-work`); sub-folders and files keep
  their Chinese names so they match what students and colleagues see in class.
- One sub-folder per course or duty. If a sub-folder grows large, add semester
  folders inside it, e.g. `班会/2026-2027-1/`.
- Keep the original `.pptx` files here; export to PDF only when sharing.

## Adding new material

1. Drop the file into the matching sub-folder (`班会/` or `前端设计与开发/`).
2. For a new course or duty, create a new sub-folder with its Chinese name and
   add a short entry under **Folders** in both `README.md` and `README.zh-CN.md`.
