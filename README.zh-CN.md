## 约定

- 顶层目录名用 ASCII（`gxsdzy-work`），子目录和文件保留中文名，与课堂上学生、同事看到的名称保持一致。
- 每门课程或每项工作一个子目录。若某个子目录文件过多，可在其中按学期再分，如 `班会/2026-2027-1/`。
- 此处保留原始 `.pptx` 文件，需要分享时再导出 PDF。

## 新增资料

1. 把文件放到对应子目录（`班会/` 或 `前端设计与开发/`）。
2. 新增课程或工作时，用中文名新建子目录，并在 `README.md` 和 `README.zh-CN.md` 的 **子目录说明 / Folders** 中各加一条。
